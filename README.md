# FAQ from Tickets

Draft support FAQ entries from a set of anonymized tickets and documented resolutions.

Copy the instructions in [SKILL.md](SKILL.md) into ChatGPT or Claude and supply the material you want reviewed. In an Agent Skills environment, install the folder with its original name.

## Example

Two resolved tickets report an export button hidden at narrow widths; one unrelated export job fails.

Expected behavior: Use the resolved layout cases for one FAQ and keep the failed job separate.
